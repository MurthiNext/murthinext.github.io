# 理想与现实的空隙在于利益
金钱在狭义上可以算作劳动力的体现，但实际上赚取金钱的方法远比实际劳动这一点多得多。也因如此使得它在现代社会中变了味，尤其体现在人类社会从资本主义到社会主义的过渡之中。

笔者曾认为很多东西沾了钱就会变了味，从赠与变为雇佣，由情感变为利益；这个冲突尤其体现在你的理想与金钱共同出现在一条线上的时候，编程算是一个比较简单的例子。开源社区是理想主义氛围最浓厚的地方之一，在这里你敲代码大概率不是为了钱，或者说钱是副产物；如果你因为喜欢计算机，喜欢编码，接下了一个程序开发的工作，那么这就是理想与现实的第一次接轨——到此为止其实比较好理解：“我只是用我的能力换取了用以活下去的财富，仅此而已。”可是如果工作的时间愈发变长，赚取金钱的手段挤压着不带利益的编码时间，甚至于几乎全部时间都用于带有利益的开发任务上，长此以往脑海中就会出现问题：“这是对的吗？”

当然是对的，人总得活下去，只是活下去的时候总让人难免回想起从前那段平凡的时光，就好像成长为人的自己回顾童年一样。

# 对不起，我需要活下去
考虑到现实世界中的人类大概无法放弃生存而拥抱另一个世界（乌托邦，或者说，天堂），为了盈利而出售自己的爱好是非常常见的，而人与人之间大多数分歧就起于这里：我无法判断你是为了⭕💰还是为了求生，这两者都是为了获得钱，但最终目的却大不相同。

这种情况在游戏社区非常常见，很多人将游戏视作自己的热爱，但看到其他人从这个游戏里赚取利益，就会开始犹豫、不解：他这么做算是热爱吗？

实际上，大多可以赚钱的游戏都出自资本主义公司，在符合 ToS 的情况下，几乎没人会管你是为了热爱还是钱；游戏公司很可能没有什么更高远的志向（除非他们在内部开始了共产主义试点），理想主义才是外来者，纷争便由此一触即发，尤其出现在 Minecraft™ 这种由社区驱动的游戏上，金钱往往是最令人内心焦灼的点。

笔者同样认为，有理想、热爱的劳作绝对是可贵的，这一点核心在于你仍然怀揣赤诚之心，没有忘记自我。但在内心想法不透明的情况下，“为爱发电”与”赚钱谋生“的纷争绝对会一直存在，且无法管制（除非有皇帝能做到这点）。

这也就是说，批评赚钱谋生的人、指责为爱发电的人，这些情况一定会有，但他们的智力水平会比立场更有说服力，很多情况下纷争其实不源于立场，而是你们的 IQ 无法统一在同一水平线上。这就好像男女对立其实是晚期智人与晚期智人类似物的对立。

# 无法改变但保持思考

提到钱，不得不提到阶级斗争；马克思曾写过太多批判资本主义、资产阶级相关的内容，这里不做赘述，一个很核心的问题是：如果我们无法改变，那么还会有抗争吗？反抗还有意义吗？

答案是有的，至少现在资本家没有在你的脑子里植入强制修改思维的脑机接口，即便是《赛博朋克：2077》也做不到，甚至还孕育出了强尼银手这样的人类。在现代法治社会下，要做点什么改变社会的动作是比较困难的，你没办法看谁不顺眼就把谁毙了替天行道，这是保护群众的一个小小的副作用，比起武力，现在的反抗更多体现在头脑风暴上（也许）。

尤其是在百年前法治尚不成熟的时代，革命本就很艰难，再由上文引申出的，现代社会更难。

这就让人产生了一种割裂感，明明马克思主义已经给出了指导，我们甚至没法去照着实行，讨厌月薪三千的工作，讨厌分配不均的世界，讨厌资本主义的恶劣，我们却什么都改变不了……？

如果有很强烈的这种意愿，笔者认为反而有些走偏了，革命不是儿戏，不是你说讨厌就能直接创造一个新的政党然后开启第三次世界大战的，更确切地说，是改变世界远比群众自己所想的难得多，就像是老师教给你了圆锥曲线，你可以大概知道这是什么，但真正上手就难得多了。

改变的前提必须是你有足够的相关学识、阅历，在此之前多加学习才是最主要的——你需要带着你的意志一直往下走，如果可以，终有一天必然会实现的，在此路程上放弃才是最可怕的，这绝对不算是对现实妥协，接受月薪三千的工作不是因为你喜欢、不是因为生来注定，而是你此刻必须要拿它来养活自己，如果放弃了这份思考，连对资本主义的厌恶都没有了……

保持思考吧。
